QUICK START
1. Open Yorks_Nexus_Materials_Projects_Client_Design_v7.html in Chrome, Edge, or Safari.
2. No installation or internet connection is required.
3. Desktop: switch between sample users from the control in the top-right corner.
4. Changes are stored only in the browser for demonstration and can be reset from the sidebar.

CORE DESIGN RULES
• Calm before clever.
• Information before decoration.
• Excel-familiar rows and keyboard-friendly controls.
• Clear current owner, actor, timestamp, revision, and status.
• One connected lifecycle: Project → Material Plan / MR → RFQ → PO → Delivery Receipt.
